## Download and install

Download **Dusk-1.2.1-universal.dmg** below. It includes Apple Silicon (`arm64`) and Intel (`x86_64`) code and requires macOS 13 or newer. Open the disk image, drag Dusk to Applications, eject the image, and launch Dusk from Applications. Quit an older copy before replacing it.

**Signing:** this download is ad-hoc signed, not Developer ID signed or notarized by Apple. macOS may block its first launch. Only proceed if you trust the project and download; use [Apple's per-app opening guidance](https://support.apple.com/en-us/102445). Do not disable Gatekeeper globally. [Building from source](https://github.com/neeraj15022001/dusk/tree/v1.2.1#build-and-run) remains available.

Download the matching checksum file to the same directory and verify:

```sh
shasum -a 256 -c Dusk-1.2.1-universal.dmg.sha256
```

## Validation and limits

The release workflow runs the effect/geometry/HID checks, builds both architectures, verifies the combined app signature, verifies and mounts the DMG, and checks the packaged binary, version, licenses, and installation files before publishing. See [release workflow runs](https://github.com/neeraj15022001/dusk/actions/workflows/release.yml).

Hosted CI does not validate a physical hinge or certify every MacBook or macOS version. Automatic effects require a compatible Apple HID hinge angle sensor; unsupported sensors leave the desktop clear. Intel and the oldest supported macOS version have not received physical hardware validation. See [testing notes](https://github.com/neeraj15022001/dusk/blob/v1.2.1/docs/TESTING.md).

Codex assisted with the packaging scripts, workflow, and documentation under maintainer direction. See the [AI policy](https://github.com/neeraj15022001/dusk/blob/v1.2.1/AI_POLICY.md). No independent security audit is claimed.
